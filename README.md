# Permadeath (Forge 1.20.1)

Mod con 50 cambios de dificultad que se activan al azar, uno por cada día de Minecraft.

- `/permadeath start` empieza (activa un cambio al instante y luego uno por día). Requiere ser operador.
- `/permadeath stop` pausa, `/permadeath reset` quita todos, `/permadeath next` fuerza el siguiente, `/permadeath status` muestra el estado.
- Al activarse un cambio: texto en rojo en el chat + animación y sonido para todos.
- Al morir un jugador: animación con su nombre para todos.
- Tecla `G`: libro con los cambios activos.

El mod debe estar instalado en el servidor y en todos los clientes.

## Descargar el .jar
Al subir este proyecto a GitHub, la pestaña **Actions** compila solo y publica el `.jar` en **Releases** (etiqueta `latest`).
